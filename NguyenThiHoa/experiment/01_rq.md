# Research Question — LLM-based REST API Test Generation and Testing

**Thành viên:** Nguyễn Thị Hoa

## RQ chính thức

For REST APIs with OpenAPI specifications, how do LLM-generated API test cases compare to traditional/manual test design approaches in terms of coverage and bug detection capabilities?

---

## PICO

- **P (Population):**
  REST APIs with OpenAPI specifications

- **I (Intervention):**
  LLM-generated API test cases (using modern Large Language Models e.g., GPT-4, Code-Llama)

- **C (Comparison):**
  Manual test design or traditional automated API testing approaches (e.g., search-based, fuzzing)

- **O (Outcome):**
  - Test Coverage (Endpoint coverage, Line/Branch coverage)
  - Bug detection capabilities (Number of real bugs/faults detected)
  - Test effectiveness / Executable rate
